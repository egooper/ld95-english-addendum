This is an addendum for Elegnaim & Helly's 2018 English translation of Lunatic Dawn: Passage of the Book (Zento e no Michishirube).

It adds full translations for all map graphics, as well as a handful of bug & localization fixes.

For a full list of changes from the original translation, please see the changelog.txt

Enjoy!

____________________

PATCH CONTENTS:

- 17 translated BMH graphic files
- Updated LD95_e.exe with everything from changelog.txt

____________________

INSTALLATION:

1. Install Elegnaim/MeshGearFox's original translation found here FIRST: https://www.romhacking.net/translations/2591/

2. Drag & drop everything from LD95_English_Addendum_May2026.zip into your game directory (e.g. \steamapps\common\LunaticDawnPotB), and overwrite.

3. Launch the game in English from LD95_e.exe

Please note that AppLocale/Locale Emulator is no longer required to run the game and may result in crashes.

____________________

NOTES:

This patch requires the Steam version of Lunatic Dawn: Passage of the Book and has not been tested with any older versions: https://store.steampowered.com/app/335420


If you want to launch the English executable through Steam, you can add the following to your launch options for the game:

"Drive:\PathToYourGame\SteamLibrary\steamapps\common\LunaticDawnPotB\LD95_e.exe" %command%

Just include the location of your LD95_e.exe inside the " ", and Steam should launch the English version instead.


A translated .chm Help file from Ortafian can be found here: https://steamcommunity.com/app/335420/discussions/0/360672383119120413/?ctp=6
